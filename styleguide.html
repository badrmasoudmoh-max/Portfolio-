Chaos primitives

Ideas
design
impact

Olive slab + grain, orange circle, torn-paper clip, sticker, swatch strip, grid-line texture. All CSS/SVG. The character layer will sit at --z-character between shapes and type.

The rules

  • Everything aligns to the 12-column grid — except elements explicitly using a chaos token.
  • Tilt only with --tilt-xs / sm / md / lg (−1.5°, 3°, −6°, 12°). Max two tilted elements per viewport.
  • One accent line per headline (orange, skewed). Never orange text on cream or cream text on orange.
  • Overlaps use --overlap and never cover headline words, buttons or nav.
  • Layer order: bg → shapes → character → type → stickers → UI.
  • Texture opacity ≤ 8%. Motion respects prefers-reduced-motion.
